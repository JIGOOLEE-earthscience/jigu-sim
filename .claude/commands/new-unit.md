요청: $ARGUMENTS

CLAUDE.md 0~5장을 따라 진행한다.

1. `git pull`, `docs/PROGRESS.md` 확인. 과목이 처음 여는 과목이면 출판사를 선생님께 확인(6장).
2. 교육과정 성취기준 확인: `docs/curriculum/<과목>.md`(목록은 `docs/curriculum/README.md`)에서 이 단원에 해당하는 성취기준 코드(예: [12지시03-02])·성취기준 해설·적용 시 고려 사항을 찾아 '다루는 범위'와 '다루지 않는 내용'을 정리. 표가 흐트러져 애매하면 `reference/`의 원본 PDF 해당 쪽만 확인. 다루지 않는 내용은 본 탭에 넣지 않고, 필요하면 접힌 '심화' 카드로만. → 다음 단계의 `docs/units/<단원>.md` 맨 위에 '## 교육과정' 항목(성취기준 코드·원문 요약·다루지 않는 내용)으로 기록. 교과서와 다르면 교과서 표현 우선, 차이를 함께 적음.
3. 교과서 분석: `textbook/<과목>/<출판사>/`에서 해당 단원 PDF를 찾아(요청에 파일·쪽이 있으면 그것) 본문 용어·수치, 모든 그림·그래프의 축(가로/세로, 단위, 범위, 눈금 간격, 선형/로그, 점선 격자, 선 색·이름), 그림 번호를 정리 → `docs/units/<대단원>-<중단원 두 자리>-<영문>.md`에 '선생님 구상 / 교과서 기준으로 반영한 것 / 다르게 처리했거나 근삿값인 것 / 미반영' 형식으로 기록(`docs/units/3-04-pressure-forces.md` 참고). 교과서를 못 찾으면 멈추고 어느 파일인지 물음.
4. 탭 구성: 선생님 아이디어가 명확하면 바로 제작(성취기준 범위를 벗어나는 부분이 있으면 반영하되 답변에서 한 줄로 알림). 없거나 모호하면 교과서 분석을 바탕으로 탭 구성안(탭 이름·핵심 조작·형성평가 주제)을 짧게 제안하고 확인받음.
5. `kit/skeleton.html` → `src/units/<파일>.html` 작성. 기준 구현(3-03·3-04·2-05)의 모듈(형성평가·그래프·3D·멈추기 옵션)을 재사용. 4장 동작 규칙(처음엔 멈춤, 체크박스 기본 해제, 속도 5단계, 값 바로가기, 멈추기 옵션)과 5장 형성평가 필수. 장면·그림은 직접 새로 그림(교과서 일러스트·사진을 캡처·트레이싱해 넣지 않음, CLAUDE.md 5장).
6. `py tools/build.py src/units/<파일>.html` → 경고 해결.
7. 검사: 로컬 서버 + playwright로 라이트·다크·400px·1366px 캡처, 라벨 겹침·가로 스크롤·콘솔 오류, 형성평가 정답 입력 확인. 캡처는 직접 보고 고침.
8. `docs/PROGRESS.md` 단원 현황에 '제작 중(미공개)'으로 추가.
9. 답변: 관련 성취기준 코드, 탭별 핵심, 교과서와 다르게 처리한 부분·확인 필요한 부분, 미리보기 주소(`http://localhost:8000/units/<파일>.html`). 사이트에 올릴지 한 줄로 묻기(올리기는 `/publish`).
