1. 밀물과 썰물? (도입)
2. 경사와 갯벌 — 해안 경사·갯벌 단면, 태백산맥 표시
3. 기조력 벡터 — 인력·원심력·기조력(합력) 벡터
4. 위도별 조석 3D — three.js, 위도별 조석 형태 + 실제 관측 자료(이어도 해양과학기지 2020년 1월)

## 교과서 기준으로 반영한 것
- 기조력은 지구 중심에 대해 대칭으로 표현(달 쪽과 반대쪽 크기 같게). 거리에 따라 비대칭으로 그리면 학생 오개념이 생긴다는 선생님 지적으로 수정.
- 3D 지구 자전축 수직, 달은 오른쪽 위(교과서 그림 구도).
- 단면도 가장 높은 곳에 '태백산맥' 라벨.
- 학생 수준 용어: '적위' 대신 '달이 지구의 적도면 위에 있다면', 형태수 F 계산 제외(아직 배우지 않음).
